# Source art milestone — NOT a game

This release contains real third-party CC0 source art and separately conditioned candidates for later Unreal Engine import. It contains no playable APK and no Unreal Engine installation.

- 14 assets: residential facade kit, fire escapes, fences, generator, tool chest, service door, utility box, street lamp, sofa, cabinet, stove, workshop cart, gate and hydrant.
- Original sources, author credits and per-file integrity manifests are included.
- Candidate GLB meshes/textures are separate from untouched originals.
- `art-preview.jpg` is a Blender studio contact sheet, **not a gameplay screenshot**.
- `art-build-report.json` records actual source/candidate geometry and runner memory/disk availability during the art build.
- `SHA256SUMS.txt` verifies the two archive files.
