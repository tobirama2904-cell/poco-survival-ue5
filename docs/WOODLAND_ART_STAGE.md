# Woodland visual refinement

Scope: improve the existing populated region's appearance, not inflate the map dimensions. The region remains 2.4 × 2.4 km. Final photoreal/art/performance acceptance is not claimed.

## Actual changes
- Replaced the severely decimated/enlarged sapling with original 12.6 m conifer geometry. 2,058 photographed twig sprigs, 9,728 triangles per tree; masked, two-sided foliage and a photographed bark normal map. This is procedural geometry using verified CC0 pine_tree_01 photographs, NOT a scanned mature-tree mesh.
- Added alpha-coverage mip settings to the Unreal importer to preserve the cutout silhouette at distance. Actual mobile appearance remains to be checked.
- Added 1,002 deterministic close-understory placements; total 7,190 nature instances. Interior/door/front approach and the southwest diagnostic path remain excluded. New close vegetation is trees, broadleaf shrubs and non-colliding ferns, not new quests or simulated wildlife.
- Ground now has scanned diffuse, normal and roughness inputs at a 3 m tile scale. All terrain POSITION values were compared with the immutable base 002 archive and remained identical; collision/world-height alignment was not redesigned.
- Rebuilt the original shelter with actual side-window openings, frames, a porch bench, stored timber and a short weathered fence. Desk and cot locations/heights used by story interactions are preserved. The six sites still share a model; this is not six completed bespoke buildings.
- Actual offline Blender asset review opened. Crowns are visibly fuller and the roof is weathered; the preview is labelled NOT AN UNREAL GAME FRAME. It is not gameplay or phone-performance evidence.
